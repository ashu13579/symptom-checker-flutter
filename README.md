**MediGuide** is an intuitive, interactive healthcare guidance mobile app built with Flutter featuring an interactive SVG/canvas anatomical body map, AI-assisted preliminary triage, and strict medical disclaimer safety compliance.

---

## ⚡ Key Highlights

- **Interactive Anatomical Body Map**: Visual symptom selector allowing users to tap specific anatomical regions (Head, Chest, Abdomen, Limbs) for granular symptom exploration.
- **AI-Assisted Educational Insights**: Generates structured preliminary triage questions and educational health information.
- **Emergency Escalation Protocol**: Prominent urgent-care detection providing instant emergency hotline redirection when critical indicators are present.
- **Privacy-First Architecture**: Zero personal health data stored on external servers; all queries cached in secure on-device storage.

---

## 🛠️ Tech Stack

- **Framework**: Flutter (iOS & Android)
- **Language**: Dart
- **UI Components**: Custom Canvas Painter, Material Design 3, `flutter_animate`
- **State Management**: Provider / Riverpod

---

## 🚀 Installation

```bash
# Clone the repository
git clone https://github.com/kodeashu/symptom-checker-flutter.git
cd symptom-checker-flutter

# Get dependencies
flutter pub get

# Run app
flutter run
```
